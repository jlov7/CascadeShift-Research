# Security

CascadeShift processes synthetic research material. Do not use production credentials, personal data, customer data, or sensitive configuration records with it.

Potential issues include code defects, dependency concerns, packaging problems, and unintended disclosure of locally supplied data. Do not post secrets or sensitive details in a public issue. This repository does not provide a confidential reporting channel or a response-time commitment.

The project makes no security, privacy, or compliance guarantee. Read [Disclaimer](DISCLAIMER.md) before use.
