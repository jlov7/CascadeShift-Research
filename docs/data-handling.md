# Data handling

CascadeShift is designed for synthetic research data. Do not use production credentials, customer data, personal data, confidential provider content, or sensitive configuration records in its worlds, tasks, reports, logs, commits, or issue reports.

The repository intentionally includes the synthetic v1 archive because it is needed to recompute and replay the historical evidence. [The archive card](data/confirmatory-archive-card.md) describes its contents and hash. The repository does not include raw measurement-v2 provider diagnostic records.

Before sharing a reproduction, remove secrets, tokens, environment files, credential-bearing output, and sensitive diagnostics. Share the smallest synthetic example that demonstrates the problem. This guidance is not a privacy or compliance determination. See [Disclaimer](../DISCLAIMER.md).
