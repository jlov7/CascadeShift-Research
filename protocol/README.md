# Historical v1 protocol material

`preregistration.md`, `freeze_manifest.json`, and `freeze_manifest.sha256` are retained as historical v1 scientific evidence. They are byte-preserved records of the completed archive, not instructions for operating version `1.3.0`.

Some commands, signatures, repository paths, and governance references in the retained material are obsolete or unavailable in this independently created repository. Do not treat them as current prototype instructions. The historical freeze records the v1 study state; it is not an independently verifiable external registration in this repository.

For current guidance, read the [technical note](../TECHNICAL-NOTE.md), [historical protocol notes](../docs/protocol-errata.md), and [reproducibility guide](../REPRODUCIBILITY.md). In particular, the current interpretation explains the rule-only C0/C1/C2 interface, the limits of the historical H2 finished-but-failed flag, and the H5 oracle-closure overlap diagnostic.

`requirement_ledger.md` is deliberately omitted because it described superseded project governance rather than scientific evidence needed to inspect the archived study.
